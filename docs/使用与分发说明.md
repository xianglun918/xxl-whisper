# xxl-whisper 使用与分发说明

> Windows 托盘常驻离线语音听写：**按住 CapsLock 说话，松开后中文直接上屏到光标处**。

---

## 一、给使用者：安装与使用

### 安装（3 步）

1. 下载 `xxl-whisper.exe`（GitHub Release 附件，或维护者直接发送），放到任意固定目录（如 `D:\Tools\`）
2. 双击运行。**首次运行会自动下载约 230MB 语音模型**（hf-mirror 国内直连，无需网盘、无需账号），底部有进度提示，等它消失即就绪
3. 托盘出现话筒图标 = 可以用了

杀毒软件若误报（Python 打包 exe 常见），加入白名单即可。

### 日常使用

| 操作 | 效果 |
|---|---|
| **按住 CapsLock 说话，松开** | 识别结果直接打在当前光标处（支持中英混说） |
| **单击 CapsLock** | 原来的大小写切换，不受影响 |
| 按住时屏幕底部 | "● 正在听…" 提示条，跟随当前显示器 |
| 右键托盘图标 | 暂停热键 / 选麦克风 / 开机自启 / 退出 |

识别全程**离线本地运行**（CPU 即可，无需 GPU、无需联网），说多长都不产生任何流量。

### 常见问题

| 现象 | 说明 |
|---|---|
| 提示"本机拦截键盘注入" | 你机器上有带全局键盘钩子的软件（uTools/豆包/ArmouryCrate 等）拦截了模拟按键。程序已自动改用备用通道上屏；若个别软件仍不进字，按提示手动 Ctrl+V（文字已在剪贴板） |
| 管理员权限的窗口里不出字 | 系统安全限制（UIPI），把 xxl-whisper 也用管理员运行可解，但会放大杀软误报，不推荐日常使用 |
| 识别太慢/太快想调 | 配置文件见下表 `num_threads` |
| 出问题排查 | 日志：`%LOCALAPPDATA%\xxl-whisper\logs\app.log`（发给维护者即可） |

### 配置文件

位置：`%LOCALAPPDATA%\xxl-whisper\config.toml`（改完重启生效）

| 键 | 默认 | 说明 |
|---|---|---|
| `hotkey` | `caps_lock` | 可换 `f2` / `f4` / `f6` / `f8` / `scroll_lock` |
| `hold_threshold_ms` | `250` | 按住少于该时长视为单击（大小写切换） |
| `mic` | `""` | 麦克风设备名；空 = 系统默认（托盘菜单也能换） |
| `num_threads` | `2` | 识别线程数，加大可提速（吃 CPU） |
| `language` | `zh` | 中文为主；`auto` 自动判别语种 |
| `restore_clipboard` | `true` | 上屏后是否还原剪贴板原内容 |
| `check_updates` | `true` | 启动及每 24 小时检查 GitHub 新版本并托盘提示（关掉则完全静默） |

### 版本升级提示

程序启动 15 秒后静默检查一次 GitHub Release（此后每 24 小时一次），发现新版本时弹**托盘通知**；
右键托盘 → **检查更新** 可立即检查，确认后自动打开下载页。网络不通时静默跳过，不影响任何功能。

### 卸载

1. 托盘退出
2. 删除 exe
3. 删除数据目录 `%LOCALAPPDATA%\xxl-whisper\`（含模型/配置/日志）

## 二、给维护者：打包与发版

### 环境要求

- Windows 10/11 x64 + Python 3.12/3.13 + [uv](https://docs.astral.sh/uv/)

### 打包

```bash
git clone https://github.com/xianglun918/xxl-whisper.git
cd xxl-whisper
uv sync              # 安装依赖（生成 .venv）
build.bat            # PyInstaller 打包 -> dist\xxl-whisper.exe（约 43MB）
```

验证产物：双击 exe，日志（`%LOCALAPPDATA%\xxl-whisper\logs\app.log`）出现
`hook installed: vk=0x14` 与 `ready: hotkey=caps_lock` 即正常。

### 质量门禁（改代码后必须全绿再发版）

```bash
uv run python -m ruff check app tests run.py scripts
uv run basedpyright app run.py
uv run pytest tests -q                       # 含真实模型集成测试（需已下载模型）
uv run python -X utf8 scripts/probe_focus.py     # 浮条焦点/定位探针
uv run python -X utf8 scripts/probe_hold_bar.py  # 残留定时器探针
uv run python -X utf8 scripts/probe_emit_chain.py # 上屏通道探针
```

### 发新版本

```bash
# 1. 改 app/__init__.py 的 __version__ 与 pyproject.toml 的 version
git add -A && git commit -m "feat: xxx"
git push
# 2. 打 tag 并附上 exe
git tag v0.x.0 && git push --tags
gh release create v0.x.0 dist/xxl-whisper.exe --title "v0.x.0" --notes "变更说明"
```

使用者从 Release 页下载 exe 即可，无需碰源码。

### 模型说明（已内置自动下载，此处备查）

- SenseVoice-Small INT8 ONNX（239,233,841 字节）+ tokens.txt（315,894 字节）
- 主源 `hf-mirror.com/csukuangfj/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17`，
  兜底 GitHub release tar.bz2；存放于 `%LOCALAPPDATA%\xxl-whisper\models\sensevoice\`
- ⚠️ 不要改用 ModelScope 的 `iic/SenseVoiceSmall-onnx`：它与 sherpa-onnx 内置的
  onnxruntime 版本不兼容（ORT API 冲突）
