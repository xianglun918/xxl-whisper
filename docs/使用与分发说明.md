# xxl-whisper 使用与分发说明

> Windows 托盘常驻离线语音听写：**按住 CapsLock 说话，松开后中文直接上屏到光标处**。

---

## 一、给使用者：安装与使用

### 安装（3 步）

1. 下载 `xxl-whisper.exe`（GitHub Release 附件，或维护者直接发送），放到任意固定目录（如 `D:\Tools\`）
2. 双击运行。**首次运行会自动下载约 230MB 语音模型**（hf-mirror 国内直连，无需网盘、无需账号），底部有进度提示，等它消失即就绪
3. 托盘出现话筒图标 = 可以用了

杀毒软件若误报（Python 打包 exe 常见），加入白名单即可。

### 日常使用

| 操作 | 效果 |
|---|---|
| **按住 CapsLock 说话，松开** | 识别结果直接打在当前光标处（支持中英混说） |
| **单击 CapsLock** | 原来的大小写切换，不受影响 |
| 按住时屏幕底部 | "● 正在听…" 提示条，跟随当前显示器 |
| 右键托盘图标 | 暂停热键 / 选麦克风 / **换热键** / 开机自启 / 检查更新 / 退出 |

换热键即时生效并自动保存（无需重启）：托盘 → 热键 → 选预设（CapsLock、F2、F4、F6、F8、Scroll Lock、鼠标侧键 X1/X2）或**「自定义按键…」**——点击后按提示按下任意键（Esc 取消，纯修饰键无效），即刻切换。被征用的键原功能在程序运行期间会被"按住说话"占用（单击仍保留原功能）。

**游戏全屏友好**：独占全屏的游戏/演示模式下，"正在听…"提示条自动隐藏（不与游戏抢占屏幕，语音识别与上屏不受影响）；无边框全屏（如浏览器/终端 F11）提示条正常显示。

**启动期间**：软件刚打开、模型还在加载（约数秒）时，CapsLock 按原生行为工作（单击切换大小写、不影响任何功能）；加载完成后才进入"按住说话"模式。

**上屏通道**（自动降级，无需干预）：
1. 键盘注入（Ctrl+V）——最快，正常机器走这条
2. 注入被拦截 → 经典控件（记事本/终端等）走 WM_PASTE 定点投递
3. 现代控件（新记事本/部分应用）走 UIA（无障碍接口）
4. 都不行 → 文字留在剪贴板，底部提示手动 Ctrl+V

识别全程**离线本地运行**（CPU 即可，无需 GPU、无需联网），说多长都不产生任何流量。

### 常见问题

| 现象 | 说明 |
|---|---|
| 提示"本机拦截键盘注入" | 你机器上有带全局键盘钩子的软件（uTools/豆包/ArmouryCrate 等）拦截了模拟按键。程序已自动改用备用通道上屏；若个别软件仍不进字，按提示手动 Ctrl+V（文字已在剪贴板） |
| 管理员权限的窗口里不出字 | 系统安全限制（UIPI），把 xxl-whisper 也用管理员运行可解，但会放大杀软误报，不推荐日常使用 |
| 识别太慢/太快想调 | 配置文件见下表 `num_threads` |
| 出问题排查 | 日志：`%LOCALAPPDATA%\xxl-whisper\logs\app.log`（发给维护者即可） |

### 配置文件

位置：`%LOCALAPPDATA%\xxl-whisper\config.toml`（改完重启生效）

| 键 | 默认 | 说明 |
|---|---|---|
| `hotkey` | `caps_lock` | 预设名（`caps_lock`/`f2`/`f4`/`f6`/`f8`/`scroll_lock`/`mouse_x1`/`mouse_x2`）或任意虚拟键码整数（如 `117`），托盘菜单改更方便 |
| `hold_threshold_ms` | `400` | 按住少于该时长视为单击（大小写切换） |
| `mic` | `""` | 麦克风设备名；空 = 系统默认（托盘菜单也能换） |
| `num_threads` | `2` | 识别线程数，加大可提速（吃 CPU） |
| `language` | `zh` | 中文为主；`auto` 自动判别语种 |
| `restore_clipboard` | `true` | 上屏后是否还原剪贴板原内容 |
| `check_updates` | `true` | 启动及每 24 小时检查 GitHub 新版本并托盘提示（关掉则完全静默） |
| `proxy` | `""` | 模型下载的 HTTP/HTTPS 代理（如 `http://127.0.0.1:7890`）；内网/代理受限时填写，优先级高于环境变量 |
| `disfluency` | `verbatim` | `verbatim` 保留嗯/呃/啊等语气词（逐字稿）；`smooth` 让 Fun-ASR-Nano 顺滑——去语气词、重复、口误，输出流畅文本（仅对该模型生效；**切到 Fun-ASR-Nano 时默认打开**） |

### 版本升级提示

程序启动 15 秒后静默检查一次 GitHub Release（此后每 24 小时一次），发现新版本时弹**托盘通知**；
右键托盘 → **检查更新** 可立即检查，确认后自动打开下载页。网络不通时静默跳过，不影响任何功能。

### 卸载

1. 托盘退出
2. 删除 exe
3. 删除数据目录 `%LOCALAPPDATA%\xxl-whisper\`（含模型/配置/日志）

### macOS 版（安装与使用）

#### 安装（3 步）

1. 从 GitHub Release 下载 `xxl-whisper-arm64.zip`，解压得到 `xxl-whisper.app`
2. 拖到任意固定目录（如「应用程序」）
3. **首次打开：右键点图标 → 选「打开」**（Control + 单击等同右键）。当前为 ad-hoc 签名、未公证，双击会被 Gatekeeper 拦下；右键打开一次后即可正常双击

仅支持 Apple 芯片（arm64），需 **macOS 15 或更高**（sherpa-onnx 预编译库在 14 及以下加载即崩，上游 [k2-fsa/sherpa-onnx#3840](https://github.com/k2-fsa/sherpa-onnx/issues/3840)）。首次运行自动下载约 230MB 模型（同 Windows 版）。

#### 首次授权（三项，必须）

mac 版需要三项系统授权，应用启动后检测并弹窗引导（点「打开设置」深链到对应面板）：

| 权限 | 用途 | 系统设置位置 |
|---|---|---|
| 辅助功能 | 注入 Cmd+V 上屏 | 隐私与安全性 → 辅助功能 |
| 输入监控 | 监听热键 | 隐私与安全性 → 输入监控 |
| 麦克风 | 录音 | 首次录音时系统弹窗授权 |

**每次更新后，辅助功能与输入监控都要重新勾选一次。** ad-hoc 构建按二进制哈希识别身份，更新后旧授权失效；应用启动会自动 `tccutil reset` 清掉过期记录，所以系统设置里复选框显示为**未勾选**，每项**勾一次**即可，不用先删再添加。将来改用 Developer ID + 公证构建可免去此步骤（尚未实现）。

源码运行时授权归属宿主终端（如 iTerm2），可用 `tccutil reset` 清掉重测。

#### 日常使用

| 操作 | 效果 |
|---|---|
| **按住右 Command 说话，松开** | 识别结果直接打在当前光标处（支持中英混说） |
| 按住时屏幕底部 | 「● 正在听…」提示条，居中；前台窗口铺满屏幕时自动隐藏 |
| 右键菜单栏图标 | 暂停热键 / 选麦克风 / **换热键** / 换模型 / 语义顺滑 / 开机自启 / 输入诊断 / 检查更新 / 退出 |

换热键即时生效并自动保存（无需重启）：菜单栏图标 → 热键 → 右 Command / F2 / F4 / F6 / F8，或**「自定义按键…」**（点击后按任意键，Esc 取消）。

mac 的 F 键默认是媒体键；要用 F2/F4/F6/F8 当热键，需按住 Fn，或在「系统设置 → 键盘」开启「将 F1、F2 等键用作标准功能键」。

**上屏通道**：Cmd+V 注入 → 剪贴板提示（mac 无 Windows 的 WM_PASTE / UIA 通道）。上屏前会先把文字写入剪贴板。

#### 常见问题

| 现象 | 说明 |
|---|---|
| 双击打不开、提示「无法验证开发者」 | ad-hoc 未公证，右键 → 打开一次即可（见安装第 3 步） |
| 更新后按住热键没反应 | 辅助功能 / 输入监控授权随更新失效，去系统设置重新勾选两项（应用已自动清掉过期记录，直接勾即可） |
| F2/F4/F6/F8 按了是调亮度/音量 | mac F 键默认媒体键，按住 Fn 或改「标准功能键」设置 |
| 出问题排查 | 日志：`~/Library/Application Support/xxl-whisper/logs/app.log`（发给维护者即可） |

#### 配置文件

位置：`~/Library/Application Support/xxl-whisper/config.toml`（改完重启生效）。键含义与 Windows 版相同（见上文 Windows 配置表），其中 `hotkey` 的 mac 预设为 `right_cmd` / `f2` / `f4` / `f6` / `f8`，或任意键码整数。

#### 卸载

1. 菜单栏图标 → 退出
2. 删除 `xxl-whisper.app`
3. 删除数据目录 `~/Library/Application Support/xxl-whisper/`（含模型/配置/日志）

## 二、给维护者：打包与发版

### 环境要求

- Windows 10/11 x64 + Python 3.12/3.13 + [uv](https://docs.astral.sh/uv/)

### 打包

```bash
git clone https://github.com/xianglun918/xxl-whisper.git
cd xxl-whisper
uv sync              # 安装依赖（生成 .venv）
build.bat            # PyInstaller 打包 -> dist\xxl-whisper.exe（约 43MB）
```

验证产物：双击 exe，日志（`%LOCALAPPDATA%\xxl-whisper\logs\app.log`）出现
`hook installed: vk=0x14` 与 `ready: hotkey=caps_lock` 即正常。

### 质量门禁（改代码后必须全绿再发版）

```bash
uv run python -m ruff check app tests run.py scripts
uv run basedpyright app run.py
uv run pytest tests -q                       # 含真实模型集成测试（需已下载模型）
uv run python -X utf8 scripts/probe_focus.py     # 浮条焦点/定位探针
uv run python -X utf8 scripts/probe_hold_bar.py  # 残留定时器探针
uv run python -X utf8 scripts/probe_emit_chain.py # 上屏通道探针
```

### 发新版本

```bash
# 1. 改 app/__init__.py 的 __version__ 与 pyproject.toml 的 version
git add -A && git commit -m "feat: xxx"
git push
# 2. 打 tag 并附上 exe
git tag v0.x.0 && git push --tags
gh release create v0.x.0 dist/xxl-whisper.exe --title "v0.x.0" --notes "变更说明"
```

使用者从 Release 页下载 exe 即可，无需碰源码。

### 模型说明（已内置自动下载，此处备查）

- SenseVoice-Small INT8 ONNX（239,233,841 字节）+ tokens.txt（315,894 字节）
- 主源 `hf-mirror.com/csukuangfj/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17`，
  兜底 GitHub release tar.bz2；存放于 `%LOCALAPPDATA%\xxl-whisper\models\sensevoice\`
- ⚠️ 不要改用 ModelScope 的 `iic/SenseVoiceSmall-onnx`：它与 sherpa-onnx 内置的
  onnxruntime 版本不兼容（ORT API 冲突）

### macOS 版（打包与发版）

#### 环境要求

- Apple 芯片 Mac（arm64）+ macOS 15+ + Python 3.12/3.13 + [uv](https://docs.astral.sh/uv/)

#### 打包

```bash
git clone https://github.com/xianglun918/xxl-whisper.git
cd xxl-whisper
uv sync              # 安装依赖（生成 .venv）
bash build.sh        # PyInstaller 打包 -> dist/xxl-whisper.app + dist/xxl-whisper-arm64.zip
```

`build.sh` 产出 onedir 的 `.app`，再用 `ditto` 打成 `xxl-whisper-arm64.zip`（保留符号链接，解压后可直接运行）。签名默认 ad-hoc；设置环境变量可切换 Developer ID：

```bash
CODESIGN_IDENTITY="Developer ID Application: ..." bash build.sh   # 供将来公证使用
```

（Developer ID + 公证尚未启用，公开发布的 zip 仍为 ad-hoc。）

验证产物：右键打开 `.app`，日志（`~/Library/Application Support/xxl-whisper/logs/app.log`）出现 `ready: hotkey=right_cmd` 即正常。

#### 质量门禁（与 Windows 同一套，改代码后必须全绿再发版）

```bash
uv run python -m ruff check app tests run.py scripts
uv run basedpyright app run.py
uv run pytest tests -q                       # 含真实模型集成测试（需已下载模型）
```

#### 发新版本

```bash
# 1. 改 app/__init__.py 的 __version__ 与 pyproject.toml 的 version
git add -A && git commit -m "feat: xxx"
git push
# 2. 打 tag 并附上两个平台的产物
git tag v0.x.0 && git push --tags
gh release create v0.x.0 dist/xxl-whisper.exe dist/xxl-whisper-arm64.zip --title "v0.x.0" --notes "变更说明"
```

Release 需同时附上 `dist/xxl-whisper.exe`（Windows）与 `dist/xxl-whisper-arm64.zip`（macOS）。
