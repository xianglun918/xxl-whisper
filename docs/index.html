Features

为“打字慢的人”造的离线听写

没有账号、没有云、没有延迟到服务器的往返。语音在你的机器上变成文字，直接落到光标处。

纯本地离线

SenseVoice 本地推理，断网也能用；语音不出本机，隐私无忧。

中英混说

中文为主，英文单词自然穿插——“开个 PR”“看下 README”照单全收。

上屏通道自适应

键盘注入 → WM_PASTE → UIA → 剪贴板提示，四级自动降级，兼容各类输入框。

热键自由

CapsLock、F 键、鼠标侧键、任意自定义键，托盘菜单即时切换。

永不抢焦点

底部状态条跟随当前显示器，独占全屏游戏自动隐藏，不打断你的工作。

一键升级

启动静默检查新版本，托盘提示直达下载页，覆盖旧 exe 即完成升级。

How it works

三步，从声音到文字

STEP 01HOLD

按住

按住 CapsLock（或自定义键），麦克风开始拾音，底部浮条提示“正在听…”。

STEP 02ASR

识别

松开瞬间，本地模型离线解码，中文与夹杂的英文单词一并转写。

STEP 03TYPE

上屏

文字自动注入当前光标处，全程无感，无需手动粘贴。

Models

两档模型，按需切换

推荐新模型

高精度 · LLM 解码
  • 约 1GB，中英混说与方言表现更优

  • 对准确率要求高时切换此模型
