xxl-whisper 是 Windows 与 macOS 双平台的离线语音听写工具。Windows 按住 CapsLock，macOS 按住右 Command；识别全程在本地完成，无需联网、不依赖任何云服务；中英混说，文字直接落在光标处。

Platforms

Windows 与 macOS，同一个离线内核

识别、录音、模型下载与更新两平台共用；只有热键钩子、上屏与状态条各有一套平台实现。

Windows 10 / 11

Windows 版

xxl-whisper.exe · 免安装
  • 下载 xxl-whisper.exe，双击即运行
  • 按住 CapsLock 说话，松开上屏；单击仍是大小写切换
  • 上屏四级降级：Ctrl+V → WM_PASTE → UIA → 剪贴板
  • 热键可换：CapsLock / F 键 / 鼠标侧键 / 自定义
macOS 15+ · arm64

macOS 版

xxl-whisper-arm64.zip · .app
  • 下载 xxl-whisper-arm64.zip，解压得到 .app
  • 首次打开：右键点图标 → 选「打开」（未公证，双击会被 Gatekeeper 拦）
  • 按住 右 Command 说话；热键可换 F2 / F4 / F6 / F8 / 自定义
  • 首次授权三项：辅助功能（上屏）/ 输入监控（热键）/ 麦克风（录音）
  • 上屏两级：Cmd+V → 剪贴板兜底
macOS 安装与权限：仅支持 Apple 芯片（arm64），需 macOS 15 或更高。当前为 ad-hoc 签名、未公证，首次打开需右键「打开」；每次更新后辅助功能与输入监控需重新勾选一次。安装、授权与常见问题见 README 的 macOS 说明，安装包见 Releases。
Features

为“打字慢的人”造的离线听写

没有账号、没有云、没有延迟到服务器的往返。语音在你的机器上变成文字，直接落到光标处。

纯本地离线

SenseVoice 本地推理，断网也能用；语音不出本机，隐私无忧。

中英混说

中文为主，英文单词自然穿插——“开个 PR”“看下 README”照单全收。

上屏按平台适配

Windows 四级降级：Ctrl+V → WM_PASTE → UIA → 剪贴板；macOS 走 Cmd+V 注入，剪贴板兜底。

热键自由

Windows：CapsLock / F 键 / 鼠标侧键 / 自定义；macOS：右 Command / F2-F8 / 自定义。托盘即时切换。

永不抢焦点

Windows 状态条跟随前台显示器；macOS 用非激活 NSPanel，不抢键盘焦点、不打断输入。

一键升级

启动静默检查新版本，托盘提示直达下载页；覆盖旧版本即完成升级。

持续听写

常开免按键：内置 VAD 只在检测到人声时识别，说完一句自动上屏；静音与背景噪音一个字都不出。

语义顺滑

一键去掉「嗯/呃/啊」语气词、重复与口误，输出流畅文本（Fun-ASR-Nano）。

How it works

三步，从声音到文字

STEP 01HOLD

按住

按住热键（Windows：CapsLock；macOS：右 Command），麦克风开始拾音，底部浮条提示“正在听…”。

STEP 02ASR

识别

松开瞬间，本地模型离线解码，中文与夹杂的英文单词一并转写。

STEP 03TYPE

上屏

文字自动注入当前光标处：Windows 四级降级，macOS 走 Cmd+V，无需手动粘贴。

Live

持续听写：不用按任何键，说完一句就上屏

内置 VAD 只在检测到人声时才识别——静音和背景噪音一个字都不出。
