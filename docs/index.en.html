Platforms

Windows and macOS, one offline core

Recognition, recording, model download and updates are shared across both platforms; only the hotkey hook, text insertion and status bar each have a platform-specific implementation.

Windows 10 / 11

Windows

xxl-whisper.exe · Portable
  • Download xxl-whisper.exe and double-click to run
  • Hold CapsLock to talk, release to type; a single tap still toggles caps lock
  • Four-level insertion fallback: Ctrl+V → WM_PASTE → UIA → clipboard
  • Swap the hotkey: CapsLock / F keys / mouse side buttons / custom
macOS 15+ · arm64

macOS

xxl-whisper-arm64.zip · .app
  • Download xxl-whisper-arm64.zip and unzip to get the .app
  • First launch: right-click the icon → Open (not notarized, so a double-click is blocked by Gatekeeper)
  • Hold Right Command to talk; the hotkey can be F2 / F4 / F6 / F8 / custom
  • Grant three permissions on first run: Accessibility (insertion) / Input Monitoring (hotkey) / Microphone (recording)
  • Two-level insertion: Cmd+V → clipboard fallback
macOS install & permissions: Apple silicon (arm64) only, macOS 15 or later required. The current build is ad-hoc signed and not notarized, so the first launch needs a right-click → Open; after every update, Accessibility and Input Monitoring must be re-checked once. Installation, permissions and FAQs are in the macOS section of the README, and builds are on Releases.
Features

Offline dictation built for people who type slowly

No account, no cloud, no round-trip to a server. Speech becomes text on your own machine and lands right at the cursor.

Fully local & offline

SenseVoice runs inference locally and works without a network; your voice never leaves the machine.

Mixed Chinese & English

Chinese-first, with English words woven in naturally — "open a PR", "check the README" are all handled.

Platform-aware insertion

Windows uses a four-level fallback: Ctrl+V → WM_PASTE → UIA → clipboard; macOS injects Cmd+V with a clipboard fallback.

Hotkeys your way

Windows: CapsLock / F keys / mouse side buttons / custom; macOS: Right Command / F2–F8 / custom. Switch instantly from the tray.

Never steals focus

On Windows the status bar follows the active display; on macOS a non-activating NSPanel avoids stealing keyboard focus or interrupting input.

One-click upgrade

Silently checks for new versions on launch and links straight to the download page from the tray; overwrite the old build to upgrade.

Continuous dictation

Always-on and key-free: a built-in VAD recognises only when you speak and inserts each finished sentence; silence and background noise produce no text.

Semantic smoothing

One tap strips filler words like "um/uh/ah", repetitions and slips of the tongue for smooth output (Fun-ASR-Nano).

How it works

Three steps from voice to text

STEP 01HOLD

Hold

Hold the hotkey (CapsLock on Windows; Right Command on macOS) and the mic starts capturing, with a floating bar showing "listening…".

STEP 02ASR

Recognize

The moment you release, the local model decodes offline, transcribing Chinese and any English words together.

STEP 03TYPE

Type

Text is injected at the current cursor: a four-level fallback on Windows, Cmd+V on macOS — no manual paste needed.

Models

Two models, switch on demand

Switch with one click from the tray; models download automatically on demand.

Default

SenseVoice-Small

Fast · Lightweight
  • ~230 MB — quick to download, quick to start
  • Runs at roughly 25× realtime on CPU
  • The go-to choice for everyday Chinese dictation
Recommended

Fun-ASR-Nano

High accuracy · LLM decoding
  • ~1 GB — better at mixed Chinese/English and dialects
  • An LLM decoder keeps long sentences and accents stable
  • Switch to this model when you need higher accuracy
Restricted network or proxy? If the automatic download fails, the app shows a dialog with manual download instructions; you can also follow the README's manual download guide to grab the files from the hf-mirror direct links, drop them into the right folder and restart.
