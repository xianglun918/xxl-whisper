# v0.8.0-beta.3 — 预发布（beta preview）

> **这是预发布版本，不建议日常主力使用。** 稳定版请继续用 v0.7.0。
> 预发布不会被「检查更新」推送，装它必须手动下载；想回退重新下载 v0.7.0 覆盖即可。

**这是第一个 CI 门禁全绿的预览包**（Windows / macOS / Linux 三平台 pytest + lint 棘轮 + tag/版本一致性全部通过）。beta.1 因流水线未就绪没有产出 Release，beta.2 是门禁红时破例放行的，**请用这个 beta.3**。

## 相比 beta.2 的变化

| 项 | 说明 |
|---|---|
| **配置文件自动升级** | `config.toml` 现在带 `config_version`。装到旧配置上启动时：先把原文件备份成 `config.toml.v1.bak`，再按新 schema 重写（`vad_min_silence_ms` / `vad_max_speech_ms` 退役成 `live_*`），托盘弹一次「配置已从 v1 升级到 v2」。**只有你亲手调过的老值才延续**，仍是旧默认值的会换用新默认 4 秒切分；坏文件不改写、不备份，照旧报错 |
| **修好「检查更新」** | 之前仓库把翻译模型包也发成 Release，`/releases/latest` 返回的是 `mt-ja-zh-v1`，版本解析失败 → 所有人静默收不到更新提示。现在改为拉 Release 列表、跳过模型包与预发布，取版本号最大的那个 |
| **CI 门禁转绿** | Linux 补装 PortAudio（原来 5 个 collection error、pytest 根本没跑起来）；去掉测试里写死的 `CapsLock` 默认热键（macOS 默认是右 Command），改用平台默认值 |

## 从 v0.7.0 起的主要新增

| 能力 | 说明 |
|---|---|
| **上屏字幕** | 独立的第二条输出通道，屏幕底部字幕条，不抢焦点、点击穿透；可回看最近 6 句（默认 8 秒/句）。输出方式三选一：只上屏 / 上屏+打字 / 只打字 |
| **边说边出** | 一句话还没说完就先显示一行变暗的「临时字幕」，说完被正式译文替换；限流 800ms，不占字幕行数 |
| **系统声音采集** | Windows WASAPI 回环，可直接听电影/网课/会议的声音来识别（`audio_source` 可切麦克风/系统声音） |
| **离线翻译** | 中→英、英→中、日→英、日→中。日→中从「日→英→中」两段改为**直译单模型**（约 145MB，实测更快更准）；NLLB 方案已移除 |
| **持续听写双节奏** | 字幕即时、打字整句：被 4 秒上限切开的片段在字幕里立刻显示，打字侧粘成整句再上屏 |
| **Whisper large-v3-turbo** | 新增第三个识别模型，日语最强（体积大、较慢） |
| **托盘菜单重排** | 一级只留 6–7 项，状态直接写在父级标签上（`离线翻译：日→中`、`输出方式：上屏+打字`），选项表单一来源 |

## 主要修复

- 菜单点击「全都不生效」：pystray 0.19.5 源码级逐条核对（菜单刷新延迟执行、不再替换菜单对象）
- `_tray` 属性与方法同名冲突导致所有菜单动作报 `'Tray' object is not callable`
- 剪贴板：连发丢字、还原时把刚写入的内容又还原回去（本版改为「先快照后写入 + 代次失效」）
- 切翻译方向时没重建识别器 → 日语被当中文识别（「翻译完全不对」的真因）
- 崩溃时静默退出：启动异常会写日志并给托盘提示
- macOS 每句话泄漏一条麦克风流
- 模型选择被吞：`whisper_turbo` 存盘后重启变回 `funasr_nano`

## 请重点验证（我这边跑不了 GUI/音频/热键）

| 场景 | 怎么看是否正常 |
|---|---|
| 按住 CapsLock 说一句 | 正常出字；松手后 CapsLock 本身仍能切大小写 |
| 持续听写 + 上屏字幕 | 字幕跟得上说话（不是说完一大段才出），底部小状态条不再重复显示同一句 |
| 系统声音 → 字幕 | 放一段日剧，声音来源选「系统声音」，字幕出日文 + 中文 |
| 打字模式（不开字幕） | 一句话只粘贴一次，剪贴板里你自己的内容事后还在 |
| 托盘逐项切换 | 每点一次都有反馈：翻译方向、输出方式、输入源、识别模型 |
| **配置升级（装到这个 beta 上先看这条）** | 如果你是覆盖安装、之前跑过旧版：启动后托盘应弹一次「配置已从 v1 升级到 v2」，配置目录里多出 `config.toml.v1.bak`。**备份里有你原来的全部设置**，出问题直接改名覆盖回去即可 |

日志里有两行能定损：`continuous: mode=subtitles|typing min_silence=… max_speech=…` 和 `endpoint→shown … forced=True/False`。

## 已知限制（写在前面，别当 bug 报）

- **翻译模型的下载只校验大小，不校验 SHA256**（ASR/VAD 两个模型是校验的）。这条会在 beta 期间修掉。
- 日语走社区微调权重（`shun89/opus-mt-ja-zh`，Apache-2.0 导出 ONNX + int8），**省略的主语和敬语仍会丢**；要更准请用「日→英」单跳。
- DRM 保护的播放器抓不到系统声音（WASAPI 回环的硬限制）。
- macOS 首次运行需要手动授予「辅助功能」和「麦克风」权限，否则热键/上屏不工作。

## 安装

从本次 Release 资产下载：

- Windows：`xxl-whisper.exe`（单文件，含校验文件 `xxl-whisper.exe.sha256`）
- macOS (Apple 芯片)：`xxl-whisper-arm64.zip`

模型首次使用时会自动下载（ASR/VAD 走 hf-mirror + GitHub 兜底，翻译走 ModelScope），不需要手动装。
